# Guest portraits

Drop photos here and they appear on the Legendary Guests cards automatically.
The filename must match the `photo` value in the `GUESTS` list near the bottom of
`index.html`:

| Guest | File to add |
| --- | --- |
| Balabhadra Bhattacharya das | `balabhadra-bhattacharya-das.jpg` |
| Vishnu gada Das | `vishnu-gada-das.jpg` |

Until a file exists the card shows an initials medallion instead — the page
checks that the image actually loads before using it, so a missing photo never
leaves an empty frame.

**What works best:** a portrait crop, roughly 3:4 (taller than wide), at least
600px on the short side, face in the upper half. Keep files under ~300KB so the
page stays quick on a phone.

**Please use photos you have permission to publish** — ideally ones the guests or
their temples have given you. This page is public, and a photo pulled from a
search result is both a copyright risk and an easy way to end up showing the
wrong person.
